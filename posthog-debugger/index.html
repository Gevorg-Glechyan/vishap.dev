What it does

Live events

See every event the moment it fires, with its decoded payload and properties.

Config and identity

Check the SDK version, token, hosts, consent state, distinct ID and feature flags.

Network delivery

List every request to PostHog with status, size and timing. Blocked and failed requests stand out.
