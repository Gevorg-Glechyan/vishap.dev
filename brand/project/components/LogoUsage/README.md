# LogoUsage

Which logo file goes where. Use the wordmark in a website header, the wool wordmark on dark and madder grounds, the favicon cut in a 16px browser tab, the tile as the app icon and the square file wherever a platform applies its own mask.

- The consumer provides only the placement. Never restyle, recolor or retype the logo.
- Header height: set the wordmark 20 to 24px tall. Keep `space-12` of gutter to its left.
- In a dark theme swap `vishap-wordmark.svg` for `vishap-wordmark-wool.svg`. The tile works on both themes.
