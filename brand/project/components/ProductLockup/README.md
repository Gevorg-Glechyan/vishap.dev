# ProductLockup

A product's logo: its icon, its name, and "by vishap" beneath. Use it at the top of a product page, in store listings and on hub cards.

- The consumer provides the icon file, the product name and, for products that extend another company's platform, the "(unofficial)" suffix.
- Set the name in `h2` and the signature in `small` `ink-subtle`. Icon size is 48px; gap is `space-4`.
- Never put the vishap mark inside the icon, and never color the name with the product color.
