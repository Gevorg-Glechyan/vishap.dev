# PageHero

The opening of a product page: icon, name, one sentence, one primary button, then exact details in mono. It shows the whole visual style in one view.

- The consumer provides the product color (set once as the accent), the icon, the name, one sentence that starts with a verb, and the install link.
- The primary button takes the product color with an `on-product` label. The secondary button is transparent with a `line-strong` border.
- One primary button per page. Left-align everything. Follow the hero with a real screenshot in a `surface` frame.
