# Logos

- `vishap-wordmark.svg` — Primary logo: the madder dragon as the V, then ISHAP in ink. Light grounds. Minimum 96px wide.
- `vishap-wordmark-ink.svg` — One color, ink. Printing, stamps, engraving.
- `vishap-wordmark-wool.svg` — One color, wool, transparent ground. Dark themes and dark photographs.
- `vishap-wordmark-on-madder.svg` — Wool wordmark on a madder panel with built-in clear space. Use where the ground is not yours to control.
- `vishap-mark.svg` — The dragon alone, madder. Inline next to text, watermarks. Minimum 16px.
- `vishap-mark-ink.svg` — The dragon alone, ink.
- `vishap-mark-wool.svg` — The dragon alone, wool, transparent ground. Dark grounds.
- `vishap-icon.svg` — App icon: a madder tile, the wool dragon and one border line, like a small rug. Store developer avatar, favicon at 32px and up.
- `vishap-icon-indigo.svg` — The same tile in indigo, for places where red would clash.
- `vishap-icon-square.svg` — Full-bleed square for iOS, Android and social avatars, which apply their own mask. No border line; the dragon sits in the central 56%.
- `vishap-favicon.svg` — 16px browser tab cut: no border line, a larger dragon.
- `vishap-stacked.svg` — The dragon above the full word. Splash screens and centered layouts only.
- `vishap-signature.svg` — "by" plus the wordmark. Product page footers and store listings.

All files are generated by `gen.py`. Change the script and regenerate; do not edit by hand.
