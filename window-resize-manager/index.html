Window Resize Manager

Sets any Chrome window to an exact size.

Add to Chrome See what it does

v1.1.2 · Chrome extension · by vishap

What it does

Presets

Apply a built-in device size, or one you saved, from the toolbar popup.

Exact sizes

Type a width and a height, such as 1280 × 800, and resize the window or the viewport to match.

Live dimensions

See the window frame and viewport dimensions while you resize.
